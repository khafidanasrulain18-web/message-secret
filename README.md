# Kartu Personal 💌

Website pesan personal untuk orang tersayang — terproteksi password,
berisi surat, foto, video, dan musik latar.

Dibuat dengan Next.js (App Router) + Tailwind CSS.

---

## 🚀 Menjalankan project

```bash
npm install
cp .env.local.example .env.local
# Edit .env.local — isi MESSAGE_SECRET dengan string acak
npm run dev
